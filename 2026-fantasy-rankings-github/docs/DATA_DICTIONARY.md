# Data dictionary

| Column | Meaning |
|---|---|
| RANK | Overall ranking in the published list |
| Player | Player name at publication time |
| GSIS ID | Stable NFL player identifier used to avoid name-matching errors |
| Team | NFL team abbreviation at publication time |
| POS | Fantasy position |
| ADP | Average draft position from the listed market sources |
| Value | Estimated auction or draft value within the ranking model |
| Pos Rank | Rank within the player's position |
| Proj Pts | Projected fantasy points under the published model |
| Roster Status | Active, reserve, free-agent or other roster designation |
| Change Notes | Explanation for material ranking changes |
| ADP Updated | Date of the most recent ADP refresh |
| Sources | Source URLs used for roster, player and market data |

The first line of each distributed CSV contains the publication date, league format and ADP methodology. The second line contains the table headers.
